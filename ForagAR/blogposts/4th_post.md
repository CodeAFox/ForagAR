This week, we worked on two parts of ForagAR that go hand in hand. We added more mushrooms for users to explore and updated the library menu in Unity so there’s more room to browse them. We also reviewed and approved several pull requests as a team, moving some of our recent work through review.

Part of this week’s work happened in GitHub. We went through several pull requests, reviewed the proposed changes, and approved the ones that were ready. With changes happening in both the interface and the mushroom assets, reviewing each pull request gave us a chance to see how the pieces fit into the same project.

The review process also helped us keep track of what each person had been working on. Some changes were visible right away in Unity, such as the updated menu. Others were easier to understand by looking at the files in the pull request, especially when they involved adding new content or assets.
In Unity, we added more tabs and made the library menu more compact. The tabs give us more ways to organize content as the library grows. Making the menu smaller also leaves more space for the content itself, so the entries have more room on screen while the navigation stays accessible.

These changes came at a good time because we were also expanding the mushroom library. With more entries to browse, the layout starts to matter more. A compact menu and a tabbed layout give us room to keep adding content without crowding everything onto the same part of the screen.
We added more mushroom entries to the library and brought more mushroom prefabs into Unity. The entries expand what users can browse in the library, while the prefabs expand the collection of 3D assets we can use in the AR experience.

Adding a mushroom involves working with both parts of the project. There’s the entry users see when they browse the library, and there’s the prefab that gives the mushroom a visual presence in Unity. Prefabs let us keep each model and its settings together as a reusable asset. As the collection grows, that makes it easier to manage the models and use them consistently across the project.

What we liked about this week was seeing the interface and the content come together. The new entries gave us more to browse, and the updated menu gave that growing collection more room.
