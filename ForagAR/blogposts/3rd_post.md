Our third lab session did not get off to the smoothest start. Alex and Salomeea had run into several problems with the application as they were doing their tasks for this session and had found themselves stuck and unable to move forward without discussing with the team.
The first issue concerned the Unity version. Both Salomeea and Alex had received warnings from Unity indicating that the project was running on a different version than the one installed on their machines, and that it needed to be updated. Alex tried updating and found that there were extensive changes which made them hesitate to commit the changes. There was some discussion about this over text before the session, but nobody wanted to be the one to make a change that could potentially break or compromise the work we had already done. We decided to leave it and discuss it at the meeting even though it meant that Alex could not complete their task for the session. After discussing and weighing our options, we agreed that the best option was to make the update so that everyone would be working in the same environment going forward, and Alex committed the changes.
The second issue came up when Salomeea tried to push some of the mushroom models to our repository. Several of the model files were too large for GitHub to accept, which made her unable to push it to the repository despite completing her task. We all took some time to research possible solutions and eventually decided to handle all of our models with Git LFS (Large File Storage). Git LFS works by storing large files on a separate remote server and keeping only a lightweight reference to them in the repository itself, which keeps the repository small and avoids GitHub's file size limits. The problem with this solution, however, was that Git LFS only tracks files that are added after it has been activated. As a result, the models Salomeea had already added were not covered, and she had to redo her part of the work.
Due to these problems, neither Alex nor Salomeea had completed their tasks for this session and we found ourselves in much the same position as at the end of the previous session. We used the remaining time to discuss our next steps and divide the work. Alex and Salomeea will return to the tasks from last session, with Alex focusing on the user interface and Salomeea redoing to import the mushroom models. Angela will search for models of other plants that we can use for the plant section of the application, while Kriszti will research additional mushroom species to expand the content we can include. Finally, Alex will also be responsible for writing the devblog for this session.
